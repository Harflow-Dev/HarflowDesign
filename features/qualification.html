    Try the interaction

    Choose Failed, then Retry qualification. While the card is busy, choose the result below or cancel. Switch the harness version to invalidate the in-flight check; its old success must be ignored.

    Completion controls are catalog fixtures, outside the app surface.

    Behavior under review

    The launch action stays unavailable while required features are unchecked, qualifying, failed, or unsupported. A result is useful only for the selected executable identity and required feature set. A runtime failure replaces earlier success. Cancellation ends this UI attempt; it does not certify a stopped engine process or undo a published receipt.

    Run workflow uses the same card for the selected candidate; multiple candidates would need a list of these cards. Settings provides an explicit check without starting a task. No state changes the selected access level or offers an unrestricted fallback.
