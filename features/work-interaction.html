Send queues the message. Send now requests immediate delivery; an engine refusal keeps it queued.

Approved by the owner on 2026-10-29 for HarflowMac #42. Queued messages are the user's own bubbles at the end of the activity, marked Queued in text. There is no strip above the composer. Streaming stays above those bubbles. Cancel is named Cancel queued message and only applies while the message is still queued. A refused Send now keeps the bubble and shows the reason under the text. Delivered text appears once, as a normal message. Undeliverable and Delivery uncertain stay in the transcript with those captions. Long text uses Show more. If you have scrolled up, the transcript does not jump; Queued messages brings you to the bubbles. Reduce Motion removes a cancelled bubble immediately; otherwise it fades out in 180 ms. Browser symbols and typography approximate native controls.
