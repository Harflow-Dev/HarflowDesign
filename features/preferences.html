Behavior under review

Keep explicit choices intact

New Session: order available agents by the fixture ranking. Model choices are ranked within the selected agent and retain a clear Default option.

Workflow node: list the configured orchestrator agent first once; list its model first only when that exact provider-qualified model is supported by the selected agent.

Explicit choices: changing the ranking sample or orchestrator fixture preserves selected agent and model. A backend change may reconcile model availability through normal editor behavior.

Unavailable choices: do not introduce agents or models that are absent from the current catalog. Keep provider-qualified model identity in fixture data.

Surface and state selectors are outside the app specimen. They expose deterministic fixture variations for review; native menus, settings navigation, and persistence are not implemented here.
